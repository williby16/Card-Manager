Hello!

This is a little personal project to create a desktop Magic the Gathering card database manager!
I use Moxfield to store my collection and build decks, but theres a lot I wish their collection manager did that it doesn't.
Largely for a more streamlines filtering and searching for cards for specific purposes, so Im building my own desktop application for it since the other big option is Manabox and is a mobile only option.

Feel free to watch my journey and I'll update this readme as more real usage becomes available!
